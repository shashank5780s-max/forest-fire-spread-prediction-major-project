The ConvLSTM notebook calculates:

```python
intersection = np.logical_and(predicted, truth).sum()
union = np.logical_or(predicted, truth).sum()
iou = intersection / union
dice = 2 * intersection / (predicted.sum() + truth.sum())
pixel_accuracy = correct / total_pixels
```

For ConvLSTM, `truth` is the next-frame mask in the notebook's pseudo-mask test arrays. It is not an independent human/labeled ground-truth mask.

## 2. Preprocessing

For TIFF, inference:

1. Read the first raster band.
2. Replace NaN and infinite values with zero.
3. Per-image min-max normalize.
4. Resize to `256 x 256`.
5. Convert grayscale to RGB.
6. Scale from `[0, 255]` to `[0, 1]`.

The evaluation notebook used the same general min-max normalization and `256 x 256` U-Net preprocessing.

For ConvLSTM, input masks are stacked in chronological frame order and converted to a `[1, 5, 1, 256, 256]` tensor.
